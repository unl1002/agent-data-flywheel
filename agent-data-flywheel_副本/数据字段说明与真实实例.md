\## 1. 用户反馈.json

**总量**：42 条。**结构**：扁平对象数组，每条是一次用户对回答的反馈记录。

\### 1.1 字段与含义

| # | 字段 | 类型 | 含义 |

|---|---|---|---|

| 1 | projectId | string | 项目 ID（NeoSight 产品为 UUID；iMasterCloud 为数字串） |

| 2 | projectName | string/null | 项目名称（可为空） |

| 3 | tenantId | string/null | 租户 ID（可为空） |

| 4 | tenantName | string/null | 租户/客户名称（可为空）※敏感 |

| 5 | projectProduct | string | 产品名（NeoSight / iMasterCloud / cloudCampus） |

| 6 | projectVersion | string | 产品版本号 |

| 7 | chatId | string | 会话 ID ★关联对话详情.detail.id 与 answers[].chatId |

| 8 | feedback | int | 反馈值：**-1=差评，0=未评价，3=好评** |

| 9 | mark | bool | 是否被人工标记（运营侧） |

| 10 | reason | string/null | 反馈原因文本（当前仅 1 条有值，飞轮关键缺口） |

| 11 | reasonType | string/null | 反馈原因类型（当前全部为 null） |

| 12 | createTime | int | 反馈时间戳（毫秒） |

| 13 | question | string | 用户问题。两种格式：①JSON 串 `{"scene":..,"question":..,"otherContext":{}}`；②纯文本 `场景：无场景，问题：xxx` |

\## 4. 推理.json

**总量**：16,201 条。**结构**：网关统一日志外壳 + `body`（LLM 请求体 JSON 串）+ `responseData`（响应，SSE 流或 JSON 或 403）。**不含 chatId，与其它三份无法直接 join**。

\### 4.1 顶层字段与含义（差异点，其余同安全护栏）

| # | 字段 | 类型 | 含义 |

|---|---|---|---|

| 1 | url | string | 固定 `/ir/robotrouter/rest/netrsn/v1/chat/completions` |

| 2 | header | string | 请求头 JSON 串（仅 x-project-id/x-project-product/x-project-name，较其它文件精简） |

| 3 | body | string | LLM 请求体 JSON 串（见 4.2） |

| 4 | isStream | int | 是否流式（1=流式） |

| 5 | firstTokenLatency | int | **首 token 延迟 ms（性能关键指标）** |

| 6 | perOutput | int | 每输出 token 平均耗时 ms |

| 7 | status | int | 状态码：200×16,195 / 403×6（403=护栏拒绝） |

| 8 | responseData | string | 响应内容，三种格式（见 4.3） |

| 9 | userType | int | 用户类型（本文件实测为 0） |

| 10 | 其余外壳字段 | 同护栏 | updateTime/totalCost/responseCost/globalRunning/tenantId(可null)/tenantName(可null)/projectId/projectName/projectProduct/projectVersion/requestId/requestType/queryParam |

\### 4.2 body（LLM 请求体，JSON 串解析后）

| # | 字段 | 类型 | 含义 |

|---|---|---|---|

| 1 | messages | object[] | 对话消息序列（共 23,382 条），每条含 role 与 content |

| 2 | model | string | 请求模型名：netmo-qwen3-32b×16,075 / netmo-default×126 |

| 3 | stream | bool | 是否流式输出 |

| 4 | enable_thinking | bool | 是否开启思维链 |
