# 真实数据版交付入口

先打开 [本轮运营看板](分析结果/dashboard.html)。所有统计都能点击查看公式、成员、分子、分母、排除记录及源文件定位。

## 查看完整原文

在本目录运行：

```bash
bash 启动看板.sh
```

浏览器访问 `http://127.0.0.1:8765`，点击“统计值 → 定位与证据 → 查看完整原文”。默认使用本机现有的原始数据目录，按文件指纹核验后读取。

复制到服务器后指定原始四份 JSON 的目录：

```bash
bash 启动看板.sh /服务器/原始数据目录
```

服务器服务仍只监听本机。在本机通过 `ssh -N -L 8765:127.0.0.1:8765 用户名@服务器` 转发后访问。直接离线打开 HTML 可看全部血缘和嵌入证据，完整原文入口会提示启动服务。

## 复用 Skill

阅读 [Skill 使用教程](agent-data-flywheel/README.md)，让 AI 读取 [SKILL.md](agent-data-flywheel/SKILL.md) 分析新一轮日志。

[设计说明](设计说明.md) 解释统计口径、AI 与脚本分工、数据飞轮及全指标溯源原理。

`分析结果/analysis.json` 是冻结的完整底表；`ai-reviews/` 是逐批 AI 评审；`reviewed_analysis.json` 是已校验报告；`dashboard.html` 是可离线打开的展示投影。网页导出的摘录包不能代替完整底表重新合并。

完整原始 JSON 沿用外部数据目录，未再次复制进交付包。保留原始字段文档、摘要、实例和项目标识符。本轮文件未上传 GitHub。
